# Global Hardware

A modern web platform for browsing, comparing, and analyzing computer hardware from around the world. Suitable for students, PC builders, and tech enthusiasts who want clear and accurate component information.

---

## Features

- Global catalog of CPUs, GPUs, motherboards, storage, and peripherals  
- Fast search and filtering  
- Side‑by‑side hardware comparison  
- Detailed specifications  
- Mobile‑friendly responsive design
